# Лабораторная работа 2 (АОИС)

Консольное приложение на C# для анализа булевой функции по выражению: построение таблицы истинности, канонических форм, полинома Жегалкина, производных и минимизации.

## Что реализовано

- разбор выражений с операциями `!`, `&`, `|`, `->`, `~`;
- переменные: только `a`, `b`, `c`, `d`, `e` (до 5 переменных);
- построение таблицы истинности;
- СДНФ и СКНФ + числовые формы (`Sigma m`, `Pi M`);
- индексная форма (вектор значений и индекс);
- проверка принадлежности к классам Поста (`T0`, `T1`, `S`, `M`, `L`);
- построение полинома Жегалкина;
- поиск фиктивных переменных;
- булевы производные (частные и смешанные, порядок 1..4);
- минимизация ДНФ и СКНФ тремя способами: расчетный, расчетно-табличный (с таблицей покрытия), табличный (карта Карно, для 1..5 переменных).

## Структура проекта

- `L2/` — основное консольное приложение;
- `TestsL2/` — unit-тесты (`xUnit`).

## Запуск

```powershell
dotnet run --project L2 -- "!(!a->!b)|c"
```

Если аргумент не передан, приложение запускается в интерактивном режиме.

## Тесты

```powershell
dotnet test L2.sln
```

## Пример допустимого ввода

- `!(!a->!b)|c`
- `!(a&b)|c`
- `a~b`
