# Лабораторная работа 4: Хеш-таблица (вариант 6)

## Вариант и коллизии
По условию используется: **разрешение коллизий с помощью цепочек на сбалансированном дереве**.

В этой реализации:
- таблица состоит из бакетов (`H = 20` по умолчанию);
- каждый бакет хранит не список, а отдельное **AVL-дерево** (`AvlChain`);
- если несколько ключей дают один и тот же хеш-адрес `h`, они попадают в одно AVL-дерево этого бакета.

Это дает логарифмическую сложность внутри коллизионной цепочки (`O(log n)` в среднем по бакету).

## Хеш-функция
Используется `RussianTwoLetterHashCalculator`:
1. Берутся первые две русские буквы ключа (регистр не важен).
2. Каждая буква переводится в индекс по алфавиту из 33 символов (`А..Я`, включая `Ё`).
3. Считается числовое значение:
   - `V = index(first) * 33 + index(second)`
   - если буква одна, вторая дополняется `'А'`.
4. Адрес бакета:
   - `h = V mod H`

## Что означает вывод в консоли
Программа печатает 2 блока: состояние бакетов и строки таблицы.

### 1) Состояние бакетов
Заголовок:
`№ | Root | Active | Total | C`

- `№` — индекс бакета.
- `Root` — ключ в корне AVL-дерева бакета (`-`, если бакет пустой).
- `Active` — количество активных (не удаленных) записей в бакете.
- `Total` — общее количество узлов (включая логически удаленные).
- `C` — флаг коллизии (`1`, если в бакете больше одной активной записи).

### 2) Строки таблицы
Заголовок:
`h | ID | V | C | U | T | L | D | Po | Pi`

- `h` — хеш-адрес записи.
- `ID` — ключ.
- `V` — числовое значение ключа.
- `C` — флаг коллизии.
- `U` — занятость (`1` — активная запись).
- `T` — терминальный узел (`1` — лист AVL-дерева).
- `L` — флаг ссылки на внешние данные (в текущей реализации всегда `0`).
- `D` — логическое удаление (`1` — запись удалена).
- `Po` — указатели на детей узла в AVL (`L:<key>`, `R:<key>`, либо оба).
- `Pi` — данные (описание термина).

## Архитектура
Решение разделено на небольшие классы с одной зоной ответственности:

- `L4/Program.cs`  
  Точка входа: создает таблицу и печатает отчет.

- `L4/Hashing/HashTable.cs`  
  Основной API таблицы: `Compute`, `Add`, `TryGet`, `Update`, `Delete`, `Contains`, `GetRows`.

- `L4/Hashing/AvlChain.cs`  
  Внутреннее хранение записей в бакете (AVL-дерево), балансировки и обходы.

- `L4/Hashing/RussianTwoLetterHashCalculator.cs`  
  Вычисление `V` и `h` по первым двум русским буквам.

- `L4/Hashing/HashTableEntry.cs`  
  Модель записи и логическое удаление/восстановление.

- `L4/Hashing/HashTableReportBuilder.cs`  
  Формирует читаемый текстовый отчет для консоли.

- `L4/Hashing/LiteratureHashTableFactory.cs`  
  Предзаполнение таблицы тестовыми данными по теме литературы.

- `TestsL4/UnitTest1.cs`  
  Набор unit-тестов на хеш-функцию, CRUD, коллизии, AVL-балансировки и отчет.

## Как запустить

```powershell
dotnet run --project .\L4\L4.csproj
```

Тесты:

dotnet test
